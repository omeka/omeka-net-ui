Component gallery

Everything on this page is compiled from scss/ in this repository, in the same order the consuming sites load it. Edit a partial, and with npm run dev running, reload to see the change. No PHP, database, or Hugo install required.

What belongs here: design tokens and components that appear on more than one site. Page-level styles stay in the project that owns the page — application/mu/views/scripts/scss/pages/ in the app, assets/scss/pages/ in the Hugo site.

Header, footer, hosting panel

All three are live on this page: the header and alert banner above, the footer below, and the hosting panel behind the button in the bottom corner. Behavior comes from js/site-header.js — try the mobile nav toggle at a narrow viewport, the nav hover pill, scrolling to collapse the alert banner, and Esc to close the hosting panel.

The markup for the header and footer is duplicated by necessity: Zend .phtml partials and Hugo Go templates can't share templates. The link lists come from data/navigation.json in this repository, so link changes are one edit; structural changes need both templates updated.
